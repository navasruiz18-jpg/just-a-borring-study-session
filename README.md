# 📚 EduBridge Library — Interactive & Offline-First Digital Platform

> An open-source, lightweight, and offline-first digital library platform engineered to democratize access to high-quality educational resources for working-class students.

---

## 📌 Overview

**EduBridge Library** goes beyond traditional static PDF repositories. It transforms standard academic texts into an **interactive, self-guided learning environment**. Built to bridge the digital and educational divide, it offers compressed offline access, inline reading support, structured learning paths, and asynchronous peer-to-peer mentoring interfaces.

---

## ✨ Key Features

* **📱 Offline-First Architecture (PWA):** Download entire books, guides, and interactive exercises on public Wi-Fi networks for seamless offline reading.
* **💡 Interactive Reading Layer:** Tap-to-explain inline glossary, adaptive chapter summaries, and immediate passage simplification.
* **🗺️ Structured Study Paths:** Step-by-step modular learning tracks with embedded micro-assessments and fully worked solution guides.
* **💬 Asynchronous Peer Mentoring:** Low-bandwidth discussion nodes allowing students to post questions attached directly to text highlights.
* **⚡ Ultra-Lightweight & Low-Spec Support:** Highly optimized for low-end Android devices (Android 6.0+) with minimal storage and RAM footprints.

---

## 🏗️ Tech Stack

* **Frontend:** React / Next.js (Progressive Web App framework)
* **Styling:** Tailwind CSS
* **Offline Storage:** IndexedDB + Workbox (Service Workers)
* **Backend:** Node.js (Express) / Go
* **Database:** PostgreSQL (Metadata & User progress) + Redis (Caching)
* **Document Engine:** PDF.js / EPUB.js with custom annotation layer
